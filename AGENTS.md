# AGENTS

If you are an AI agent working in this repository:

1. Read `PROJECT_SPEC.txt` first — it is the source of truth for what
   TradeFlow is and how it is supposed to behave.
2. Then read the role file for whichever Three Man Team role you are acting
   as in this session:
   - `ARCHITECT.md` — planning, decisions, briefs.
   - `BUILDER.md` — implementation.
   - `REVIEWER.md` — review and verification.
3. Check `handoff/ARCHITECT-BRIEF.md` for the current active step's scope
   before writing any code — do not build ahead of the current step.
