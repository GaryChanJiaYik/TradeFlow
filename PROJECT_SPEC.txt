12. PRICE CROSSING LOGIC

This is extremely important.

Do NOT implement:

current_price >= target

as the sole condition for CROSS_UP.

A crossing must actually occur.

CROSS_UP:

previous_price < target
AND
current_price >= target

CROSS_DOWN:

previous_price > target
AND
current_price <= target

CROSS_BOTH:

A valid upward OR downward crossing.

The system should not repeatedly trigger while the price remains
on the same side of the threshold.

============================================================
13. ONCE ALERT

If an alert is:

ONCE

Then:

First valid crossing:
Trigger

After successful trigger:
Mark consumed/triggered
Do not trigger again

============================================================
14. EVERY_TIME ALERT

If an alert is:

EVERY_TIME

Then each valid crossing may trigger.

However, do not send repeated notifications merely because the
price continues moving above or below the target.

The price must cross the threshold again.
